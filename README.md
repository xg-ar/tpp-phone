# TPP Phone — código fuente

Código fuente de la aplicación Android **TPP Phone** (`ar.com.tpp.phone`), de TELEFONÍA PÚBLICA Y PRIVADA S.A., desarrollada y operada por XG Networks.

Está basada en [Linphone Android](https://gitlab.linphone.org/BC/public/linphone-android) © Belledonne Communications y se distribuye bajo la licencia **GNU GPL versión 3 o posterior** (ver `LICENSE.txt`).

- Versión: 1.0.0
- Compilar: `./gradlew assembleTppphoneRelease` (requiere un `google-services.json` propio de Firebase y una clave de firma propia, que no forman parte de este repositorio).

Consultas: prepago@tpp.com.ar
